# 실기시험: 미니 방명록

출처: 사용자가 제공한 `퀴즈29.md.pdf` (2026-09-30, 1쪽). 시험 시간 14:40-16:30 KST.

## 필수 기능

- 회원가입·로그인 없이 누구나 이름, 메시지, 비밀번호로 글을 작성한다.
- 누구나 이름, 메시지, 작성 시각이 보이는 전체 목록을 최신 작성 순으로 본다.
- 글 수정은 메시지 내용만 바꾸며, 작성 때 사용한 비밀번호가 맞을 때만 허용한다.
- 글 삭제도 작성 때 사용한 비밀번호가 맞을 때만 허용한다.
- 수정·삭제 비밀번호가 틀리면 동작을 거부하고 화면에 이유를 알린다.
- 화면에 개발자 `이이삭`과 학번 `202204258`을 표시한다.

## 구현 판단

시험지에서 맡긴 세부 사항은 단순하게 정한다. 비밀번호 원문은 저장하거나 응답하지 않고, 서버에서 안전한 해시로 검증한다. 입력 길이를 제한하고 SQL은 매개변수화한다. 메시지 수정 후에도 최초 작성 시각과 최신 작성 순서를 유지한다. 별도의 관리자·로그인·ORM은 추가하지 않는다.
